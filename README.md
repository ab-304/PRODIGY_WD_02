# PRODIGY_WD_02

# Task Description

Create a stopwatch web application using HTML, CSS, and JavaScript. The application should allow users to start, pause, and reset the timer, as well as record lap times.

# What I Built

* A functional stopwatch with Start, Pause, Reset, and Lap features
* Dynamic time display in HH:MM:SS format
* Lap time recording system

# Features

* Start the stopwatch
* Pause the timer
* Reset the timer and clear laps
* Record lap times

# Technologies Used

* HTML (Structure)
* CSS (Styling)
* JavaScript (Functionality & Logic)

# How It Works

* The stopwatch uses JavaScript `setInterval()` to update time every second
* Time is displayed in hours, minutes, and seconds format
* Lap times are dynamically added to a list
